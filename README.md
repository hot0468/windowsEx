# windowsEx

한 달 휴가에서 돌아온 직장인이 되어, 가짜 Windows 데스크톱 안에서 흩어진 정보를 찾아
그날의 업무 요청을 처리하는 브라우저 방탈출 게임.

메일·메신저·사내 포털·위키·검색 포털·파일 탐색기를 오가며 단서를 모으고,
올바른 파일과 금액으로 거래처에 회신하면 하루가 끝납니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 317 tests
npm run build
```

브라우저만 있으면 됩니다. 서버도, 계정도 필요 없습니다.

## 무엇이 들어 있나

**셸** — 창 드래그·크기 조절·최소화·최대화, 작업표시줄, 시작 메뉴, 바탕화면 아이콘,
드래그 앤 드롭, 저장/불러오기/새 게임, 자동저장.

**앱 15종** — 메일(웹메일 스타일 작성 화면), 업무용/사설 메신저, 브라우저,
파일 탐색기, 메모장, 사진 뷰어, 한글 문서(인쇄), PDF 뷰어, 거래처 전용 문서 뷰어,
슬라이드, 스프레드시트(셀 편집), VPN 클라이언트, 설치 마법사,
명령 프롬프트(`ipconfig /all`, `ping`). 화면 잠금은 시작 메뉴·Ctrl+Alt+L·4분 방치.

**파일 60여 개** — hwp·xlsx·pptx·txt·jpg가 뒤죽박죽 섞인 폴더 트리. 진짜 견적서 하나를
찾으려면 미끼 여덟 개를 헤쳐야 합니다.

**브라우저 안의 인터넷** — 검색 포털(장소·기업정보·용어사전·뉴스·지식Q&A·블로그, 첫 화면 주요 기사),
사내 포털(그룹웨어 대시보드와 게시글), 사내위키(문서 트리와 표), 가게 상세 페이지와 예약,
직장인 익명 커뮤니티 '퇴근길', 민원 발급 포털 '정부25', 동행복권 당첨확인.
거래처 파트너 포털과, 검색 결과 맨 위에 붙는 수상한 무료 프로그램 광고까지.

## 진행 방식

하루 단위로 굴러갑니다. 하루치 요청은 첫날 다섯 건에서 시작해 날마다 늘어 닷새째엔 스물한 건입니다.
첫날은 정해진 다섯 건이지만, 둘째 날부터는 그날 꼭 해야 하는 한두 건 말고는
**요청 백여 개가 담긴 풀에서 무작위로 뽑힙니다** — 한 판에 쓰이는 건 그 절반이라,
다시 하면 다른 한 주가 옵니다.
그걸 다 끝내면 "아직 할 일이 남았습니다 — 야근할까요?" 하고 묻습니다. 야근을 고르면
요청이 세 건 더 들어옵니다. 그러지 않으면 그날은 거기서 끝입니다.
하루를 모두 끝내면 **퇴근** 화면이 뜨고,
컴퓨터가 다시 시작되면서 다음 날 아침 브리핑과 새 메일이 도착합니다.
날짜가 바뀌면 사내 공지와 소식도 함께 바뀝니다.

둘째 날에는 필요한 견적서가 휴지통에 버려져 있어 복원해야 하고, 정보보안팀이 사내 VPN
전환을 알려옵니다. 사내 포털 자료실에서 클라이언트를 내려받아 설치하고, 서버 이름이
해석되지 않으면 hosts 파일에 직접 한 줄을 적어야 연결됩니다. 연결하면 뜨는 세션 ID 를
보고해야 하고, 셋째 날 사내 드라이브도 이 VPN 을 켠 채로만 열립니다.
셋째 날에는 정보보안팀이 사내 드라이브 접속을 부탁하는데, 메모장으로
`C:WindowsSystem32driversetchosts` 를 열어 주소를 직접 적어 넣어야 열립니다. 그 파일에는
누가 적었는지 모를 줄이 하나 더 있고, 그 주소로 들어가면 사내망에서만 열리는 익명 소통방이 나오는데,
거기에 궁금한 걸 익명으로 물어보면 누군가 답을 해줍니다 — 답 자체가 아니라, 어디를 봐야 하는지를요.
또한 정보보안팀이 명령 프롬프트로만 볼 수 있는 MAC 주소를 묻고, 팀장이 시킨 출력은
복합기가 용지 걸림을 일으켜 사내위키의 조치 순서를 찾아 그대로 눌러야 끝나며,
발주현황 시트의 셀을 직접 고치고, 외근 중인 동료와 엄마에게는 파일을 채팅창에
끌어다 놓아 답합니다. 회계팀이 4대보험 가입내역 확인서를 요구하면 정부25에서
휴대폰 인증번호(톡톡으로 옵니다)로 본인확인을 마치고 PDF를 받아 보내야 합니다.
넷째 날에는 D유통이, 다섯째 날에는 E마트가 거래처로 등장하고, 정부25에서 뗀 서류·워크숍 사진·
휴대폰 캡처까지 온갖 곳에서 답을 찾게 됩니다. D유통이 보내온 거래조건서는 자기네 전용
형식이라, 파트너 사이트에서 뷰어를 받아 설치해야 열립니다. 그 안에만 적혀 있는 품의번호가
회신에 들어가야 합니다.

받아서 실행하는 것이 늘 안전하지는 않습니다. 정부25는 본인확인 전에 키보드 보안
프로그램을 깔라고 하고, 검색창에 '한글 뷰어'를 넣으면 결과 맨 위에 광고가 하나 붙습니다.
정식 배포본과 그렇지 않은 것을 가르는 것은 어디서 받았는지뿐입니다.

엔딩은 여섯입니다. 다섯째 날 퇴근을 누르면 보통은 불금이 지나고 주말이 오고, 월요일에
모니터가 다시 켜집니다 — 그냥 평범한 한 주였습니다. 그러나 받은편지함 구석의 평범한 제목 하나 — 인사총무팀 경조사 안내 — 를 **열어 본**
플레이어에게는 다른 엔딩이 열립니다. 검색 포털의 사고 기사와 퇴근길의 괴담은 그리로
이끄는 힌트입니다 — 왜 팀장이 매일 "쉬엄쉬엄 해요"라고 했는지,
엄마가 왜 자꾸 귤과 돈을 보냈는지, 괴담의 주인공이 누구였는지.
그리고 닷새 동안 화면을 한 번도 잠그지 않은 — 자리를 한 번도 뜨지 않은 — 플레이어에게는
세 번째 결말이 있습니다. 그리고 "역대 최고 100억 당첨금 아직 미수령"이라는 기사를 보고
가방 속 복권 용지의 일련번호를 게임 곳곳에서 조각조각 모아 동행복권에서 확인한 플레이어에게는,
네 번째 — 유일하게 살아 있는 채로 끝나는 결말. 단, 그 메일을 이미 열었다면 늦었습니다.
닷새를 내리 야근하면 과로 엔딩으로 빠지고, 한 주 내내 틀린 답이 너무 많으면 인사팀이
권고사직 명단을 들고 옵니다 — 퇴직금 두 배와 실업급여 중 하나를 고르는 결말 둘.

거래처 회신을 세 번 잘못하면 담당에서 배제되어 게임이 끝납니다.
잘못 보내면 팀장이 무엇이 틀렸는지 짚어주고, 메신저에서 답을 틀리면
힌트가 한 단계씩 구체적으로 바뀝니다.

## 구조

```
src/
├─ shell/          창 시스템, 작업표시줄, 바탕화면, 소리
├─ apps/           앱 15종
├─ engine/store.js 전역 상태와 순수 헬퍼(정답 판정, 검색, 창 배치…)
├─ scenarios/      workday.json — 게임 내용 전부
└─ assets/         사진·아이콘
```

**게임 내용은 전부 `workday.json` 한 파일에 있습니다.** 파일과 폴더, 메일, 대화와
질문, 사이트, 장소, 뉴스, 하루치 요청 목록까지 데이터라서, 날을 추가하는 일은
JSON에 `days` 항목을 하나 더 쓰는 일입니다.

코드는 그 데이터를 읽어 그리는 뷰어이고, 규칙(정답 판정·힌트 단계·창 배치·검색)은
순수 함수로 분리해 테스트로 묶여 있습니다.

## 테스트

317개. UI가 아니라 **게임이 깨지는 방식**을 검사합니다.

- 플레이어가 입력해야 하는 답이 게임 안 어딘가에서 실제로 찾아지는가
- 그 답이 클릭 가능한 선택지로 새어 나가지 않는가
- 잠긴 페이지의 내용이 검색 결과에 뜨지 않는가
- 어떤 대화도 무한 반복되거나 막다른 길로 끝나지 않는가
- 막힌 플레이어가 검색할 법한 112개 단어가 전부 결과를 내는가
- 익명게시판 글에 퍼즐 답이 새어 나가지 않는가
- 프린터 수리 순서가 위키에 적힌 순서와 일치하는가
- 파일을 원하는 질문은 실제 있는 파일을 가리키고, 셀 목표는 실제 있는 셀을 가리키는가
- 잠금 화면 비밀번호를 플레이어가 이미 본 사원증에서 읽어낼 수 있는가
- 하루가 요청 열 건으로 맞춰져 있는가
- 한 대화에 그날 질문이 두 번 오면 앞 질문이 지워지지 않고 뒤로 줄을 서는가
