# 매일 쌓이는 피드 — 설계

2026-08-24. 뉴스·퇴근길·소통방·포털 소식이 게임 내 날짜를 따라 늘어난다.

## 방식

- 항목에 `day: 2~5` 태그. 그 일차 아침부터 보이고, 이후로도 남는다(누적). 태그 없는
  항목은 처음부터 있던 것.
- `visibleByDay(items, day)` — 달력 필터. `boardPosts(posts, day)` — 필터 + 안정 정렬로
  새 날짜 글이 위로(같은 날 안에서는 작성 순서 유지). `portalFeed(scenario, base, day)` —
  포털 소식을 교체 대신 누적: 오늘 → 어제 → … → 기존 고정 공지.
- 배선: Browser(첫 화면 주요 기사·뉴스 검색·기사 페이지 모두 미래 기사를 숨김),
  Board(퇴근길·소통방 공용), Portal.

## 분량과 방향

일차 2~5에 뉴스 2건 + 퇴근길 2건 + 소통방 1건씩(총 20건). 한 주의 서사가 날짜순으로
진행된다: 감원 바람(2일) → 익명게시판 명예훼손 판결·괴담 확산 스레드(3일) → 야근과
건강·감사팀 소명 소문(4일) → 무연고 미수령 복권 기사·AR-1877 목격담(5일). 어떤 글도
정답 문자열·플레이어의 죽음을 확정하지 않는다(누출 검사 전수 통과).

## 테스트 (`test/feed.test.js`)

필터·정렬·포털 누적 규칙, 매일 최소 분량(뉴스 2·게시판 1), 태그 글의 완전성(필드·댓글),
날짜 표기가 그 일차 달력과 일치. 기존 ending.test의 "사고 기사가 첫 화면에" 검사는
1일차 첫 화면 기준으로 고정(뒤늦게 도착한 기사가 밀어내지 못하도록).
