# 윈도우 UI 방탈출 게임 — 설계 문서

날짜: 2026-08-23

## 개요

브라우저에서 실행되는 Windows 11 스타일 가짜 데스크톱 방탈출 게임.
주인공은 한 달 휴가 후 복귀한 직장인. 게임 시작 시 업무 메신저로 이번 판
목표를 받고, 가상 컴퓨터(파일탐색기·브라우저 포함) 안에서 정보/파일을 찾아
올바른 메일 회신을 보내면 클리어.

## 확정 사항

- 플랫폼: 브라우저 웹앱
- 스택: React + Vite (+ zustand 전역 store, vitest)
- 룩: Windows 11 스타일 (둥근 모서리, Mica풍 반투명, 가운데 정렬 작업표시줄, Segoe UI)
- 첫 버전 앱: 메신저, 메일, 파일탐색기, 메모장, 브라우저 — 5종
- 시나리오: 수제 1개, 내용은 전부 JSON 데이터로 분리
- 게임 규칙: 시간제한/시도제한 없음. 틀린 회신 → 상대가 힌트성 답장
- 아키텍처: 시나리오 데이터 중심 (셸/앱 = 뷰어, 콘텐츠 = scenario.json)

## 프로젝트 구조

```
windowsEx/
├─ src/
│  ├─ shell/          # 바탕화면, 작업표시줄, 시작메뉴, 창(Window) 시스템
│  ├─ apps/           # Messenger, Mail, FileExplorer, Notepad, Browser
│  ├─ engine/         # zustand store + 시나리오 로더 + 정답 판정
│  └─ scenarios/
│     └─ ep1.json     # 첫 판 데이터 전체
```

## 창 시스템 (shell)

- 셸이 열린 창 목록을 store로 관리: 드래그 이동, 최소화/최대화/닫기,
  클릭 시 맨 앞으로(z-index), 작업표시줄에 실행 중 앱 표시.
- 시작메뉴는 앱 5종 실행 런처 수준으로 최소 구현.

## 데이터 흐름

1. 시작 시 `ep1.json` 로드 → 전역 store에 적재.
2. 각 앱은 store를 읽어 렌더. 플레이어 행동(읽은 메일, 연 파일,
   방문 기록)도 store 플래그로 기록.
3. 저장/불러오기 없음(한 판 10~20분). 새로고침 = 새 게임.

## 앱 5종

| 앱 | 역할 |
|---|---|
| 메신저 | 시작 시 팀장 브리핑 수신. 읽기 전용 + 간단 선택지 답변 |
| 메일 | 받은편지함(단서+노이즈 메일) + 회신 작성. **회신 = 정답 제출** |
| 파일탐색기 | 가상 폴더 트리(바탕화면/문서/다운로드). 더블클릭 → 메모장 |
| 메모장 | txt 뷰어. 단서 파일 열람 창구 |
| 브라우저 | 주소창 + 즐겨찾기 + 방문기록. 가짜 사이트 3~4개(게임 내 데이터, 실제 인터넷 접속 없음). 잘못된 URL → 가짜 "연결할 수 없음" 페이지 |

## 첫 판 "복귀 첫날" 시나리오

1. 부팅 화면 → 바탕화면 → 메신저 알림.
2. 팀장: "거래처 A상사가 견적서 최종본 다시 보내달라고 난리. 메일 확인 후 오늘 중 회신."
3. 메일함: A상사 담당자 메일 — "견적서 **최종본** + **확정 단가** 회신 요청". 스팸/사내공지 노이즈 메일 포함.
4. 단서 사슬:
   - 다운로드: `견적서_v1.txt`, `견적서_v2.txt` (미끼, 단가 "미정")
   - 문서: `견적서_최종_진짜최종.txt` (진짜, 단가 칸 "사내위키 참조")
   - 브라우저 방문기록: 사내 위키 URL → 품목별 단가표 페이지
   - 바탕화면 메모: 위키 로그인 비밀번호 힌트 (가벼운 퍼즐 1개)
5. 클리어: A상사 메일 회신 — 올바른 파일 첨부 + 본문에 올바른 단가 →
   성공 답장 + 클리어 화면.

## 정답 판정 (선언적, ep1.json 내)

```json
"goal": {
  "replyToMail": "mail_client",
  "requiredAttachment": "file_quote_final",
  "requiredKeywords": ["3,450,000"],
  "wrongAttachmentReply": "이거 예전 버전인데요? 최종본 부탁드려요.",
  "missingKeywordReply": "단가가 안 보이네요. 확인 부탁드립니다."
}
```

- 첨부가 틀리면 `wrongAttachmentReply`, 키워드 누락이면 `missingKeywordReply`가
  NPC 답장으로 도착 — 실패가 아니라 힌트 유도.
- 첨부 정확 + 키워드 포함 → 클리어.

## 에러 처리 / 테스트

- 정적 데이터 앱이라 에러 처리 최소. 잘못된 URL 입력은 가짜 오류 페이지로 연출.
- vitest: 정답 판정 로직(goal 매칭) 유닛 테스트만. 셸/앱 UI는 수동 확인.

## 범위 제외 (첫 버전)

- 저장/불러오기, 시간제한, 랜덤 생성, 다중 시나리오, 잠금장치(로그인 화면 등),
  풍성한 데코 앱(휴지통·설정·계산기 등), 사운드.
