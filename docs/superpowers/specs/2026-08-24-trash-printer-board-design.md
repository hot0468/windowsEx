# 휴지통 복구 · 프린터 이벤트 · 익명게시판 — 설계

2026-08-24. 세 기능 모두 기존 시스템(파생 fs 뷰, ask/grant, 사이트 레이아웃) 재사용.

## ③ 휴지통 복구 퍼즐 (2일차 통합)

- `workday.json`: 견적서_B물산.hwp(`file_qb`) 항목에 `deleted: true`. 데이터는 B물산 폴더에 그대로 두고, 뷰만 휴지통으로 보낸다.
- `store.js`: `restored: {}` 상태 + `restoreFile(id)` 액션(PROGRESS에 `restored` 추가). 파생 헬퍼 `fsView(fs, { pinned, restored })` — 기존 `fsWithPinned`를 확장: `deleted && !restored[id]`인 파일은 원래 폴더에서 빠지고 휴지통에 나타난다.
- `FileExplorer.jsx`: 휴지통 안 파일의 우클릭 메뉴에 **복원** (→ `restoreFile`). 휴지통 파일은 드래그 첨부 불가.
- `FileDialog.jsx`(첨부 선택): 휴지통 루트 숨김 — 복원 없이는 첨부 불가.
- 단서: 2일차 최민서 대사에 자백 추가 — "휴가 중 폴더 정리하다 B물산 견적서를 실수로 지운 것 같아요, 휴지통 확인해 보세요."
- 휴지통의 기존 미끼(BS-100 구버전 견적서_최종.hwp)가 자연스러운 함정이 된다.
- 플레이어 임의 삭제 기능은 만들지 않는다 (퍼즐에 불필요).

## ④ 프린터 이벤트 (2일차 요청 +1)

- 시나리오에 `printer` 블록: `{ error: 'E-04 용지 걸림', steps: [올바른 버튼 순서], buttons: [...], receipt: 'P-1042' }`.
- `Hwp.jsx`에 **인쇄** 버튼 → 프린터 대화상자(새 컴포넌트, Hwp 내부 오버레이). 처음엔 E-04 에러. 버튼 5~6개 중 위키가 알려주는 순서(후면 커버 열기 → 걸린 용지 제거 → 커버 닫기 → 다시 인쇄)대로 누르면 출력 성공, 접수번호 P-1042 표시. 틀린 버튼은 에러음 + 순서 리셋.
- 위키에 **사무기기 안내** 페이지: 오류 코드 표(E-01 토너, E-04 용지 걸림 …)와 E-04 해결 순서.
- 2일차 ask 추가: 박 팀장 "B물산 견적서 출력해서 책상에, 끝나면 접수번호 알려줘요" — accept `P-1042`, grant `print`. objective `print` 추가, 2일차 requests에 등록.
- 프린터 수리 상태는 컴포넌트 로컬 (대화상자 닫으면 다시 — 허용).
- 테스트 완화: "매일 요청 수 동일" → 최대-최소 차 1 이내.

## ⑥ 익명게시판 — 독립 사이트 '퇴근길'

- 새 사이트 `{ url: 'toegeun.kr', title: '퇴근길 - 직장인 익명 커뮤니티', layout: 'board', board: {...} }`. `login`·`requiresIp` 없음 → siteView가 바로 ready.
- `board` 데이터: `posts: [{ id, title, company, author(닉), time, likes, comments: [{author, text, likes}], body: [...] }]`. 글 10개 내외 — AR주식회사 언급 글, 프린터 썰, 복귀 후유증 글 등. 퍼즐 답·비밀번호·단가는 싣지 않는다.
- `Board.jsx`: 글 목록 ↔ 글 상세, Portal의 게시글 뷰처럼 로컬 state. 스타일은 커뮤니티 톤(회사 태그 배지, 좋아요·댓글 수).
- 북마크에 '퇴근길' 추가 — 발견 경로.
- 테스트 수정: "모든 사이트 로그인 필수"·"모든 사이트 IP 게이트" 2건은 `site.login`이 있는 사내 사이트만 검사.

## 테스트

- 기존 스위트 유지 + 위 완화 2건.
- 신규: `deleted` 파일이 휴지통 뷰에 나타나고 복원 후 제자리로 돌아오는지(`fsView`), 프린터 순서 판정(순수 함수), board 글 무결성(제목·본문·댓글 형태), 그리고 board에 퍼즐 답이 안 실렸는지.
